## 记录规则

- 概要设计先采用不依赖 OD-03 选择的稳定抽象。
- 插件加载器按 OD-01 的裸 so + manifest 交付规范与 OD-02 的稳定 C ABI 设计；Node 内部可使用 C++，但禁止跨边界传递 C++ ABI 对象。
- 插件卸载器按 OD-04 默认逻辑卸载设计；物理 dlclose 仅作为显式、受安全条件约束的可选路径。
- OD-03 的一键联动替换按“逐会话 Mutation + 聚合结果”语义设计，不提供跨会话原子回滚。
- Mutation 必须覆盖插入单个或连续 Node 链、替换 Node、删除分支或连续 Node 链；插入/替换以候选拓扑预热和重协商为前置，删除分支/链不得隐式删除共享依赖。
- 所有后续新增开放问题继续追加至此文件。
